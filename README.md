# 结构与流 · Market Structure Atlas

一个默认只监听 `127.0.0.1` 的 SMC、ICT 与 Order Flow 交互学习服务器。课程从 K 线、周期、Bid/Ask、数据血统与 1R 开始，把价格结构视为“待验证叙事”，把成交与盘口视为“执行证据”，并提供新手翻译层、来源指纹检查、学习进度、支持中文输入法与课程跳转的术语检索、小测、交互图解和分阶段案例推演。

## 零基础学习路径

课程按三个层级组织，共 21 个学习单元：

1. `00 · Foundation`（7 课）：OHLC、周期嵌套、市价/限价、Spread/Slippage、成交量数据来源、R 倍数、策略期望、交易时段，以及马丁网格的仓位路径风险。
2. `01 · Framework`（7 课）：SMC/ICT 的结构、内外部流动性、Inducement、Dealing Range、Premium/Discount、OB、Breaker、FVG 与多周期假设。
3. `02 · Evidence`（7 课）：撮合、Footprint、Delta、吸收、Volume Profile、Stacked Imbalance、拍卖极值、DOM 事件与结构 × Order Flow 合流。

新手模式默认开启。每课在专业正文之前提供一句白话、生活类比、固定读图顺序、最常见误解与先修提示；开启后课程正文与翻译层也会使用更大的阅读字号。课程目录可随时收起进入全宽专注阅读，开关与目录状态都只保存在本机浏览器中。全站含 21 张交互图，涵盖策略期望、时段上下文、马丁网格敞口、流动性嵌套、Dealing Range、Volume Profile、拍卖极值和 DOM 事件回放。图中的成交、盘口与仓位数据均为教学模拟，不代表真实市场或回测结果。

## 深度课程与课内案例

21 节课现在全部包含第二遍“深度学习”层：一段完整概述、两个机制章节、两个对照案例和三项独立练习。机制章节负责说明概念为什么成立、按什么顺序识别以及哪些信息不能由图表证明；对照案例则固定拆成“情境 → 可观察事实 → 三步推理 → 决策 → 失效 → 新手结论”。

全课程共有 42 个课内微型案例，每课两个。第一个通常展示条件较完整的情境，第二个有意展示失败、数据冲突、假突破、错误锚定或 No Trade。例如 `1R` 课把具有正保守期望的 2R 样本与仍然负期望的 3R 样本并排；流动性课把扫低收回与高点外建立新价值并排；Footprint 课把主动买入推动价格与“满屏绿色但价格不动”的吸收冲突并排。它们与案例室的六个五阶段大型档案互补，而不是替代关系。

每个课内微型案例现在都带一张本地 SVG 实例图；五个教材式长章节的 15 个案例也使用同一视觉系统，全站共 57 张案例示意图。图中统一标出观察区/风险带、价格或结构路径、事件节点、成交/活动证据条和成立/失败/冲突结果，并根据课程切换为 OHLC、周期、执行、数据血统、1R、时段、敞口、结构、区域、Profile、Footprint 或 DOM 语法。每张图都有可访问标题和“能说明 / 不能说明”图注，明确它是教学结构示意，不是历史行情截图或收益证明。

每节课的深度讲解现在先显示“这一页先懂这些词”：全站 21 节课共 130 张首次阅读术语卡，定义来自本地课程词典。入口课另外手写了时间窗口、开高低收、实体、影线与交易时段八个零基础解释，并用 `O=100 / H=108 / L=97 / C=106` 的 15 分钟模拟 K 线逐步演算四个数字能说明和不能说明的内容。

每课的原有专业笔记、交互图、测验、完成进度和来源仍然保留。课程页显示包含深度层的预计学习时间；课内案例数字和价格均为教学模拟，不是历史回测或策略收益证明。

### 教材式 DFS 长章节

在原有深度层之上，课程沿知识树完成了 5/5 轮教材式扩容，共新增 14061 个中文理论正文字符和 15 个成立/失败/冲突案例。第一轮从 `订单如何成交 → 流动性为何聚集 → Sweep 与 Acceptance 如何区分` 展开，为 `01.3 · 流动性` 加入约 3315 个中文字符的理论正文（不含案例、练习、清单和来源）、三个完整案例和 38 分钟预计阅读时间。第二轮沿着 `外侧接受与失败接受` 深挖到停留时间、成交分布、Developing POC/Value Area 迁移和回测行为，为 `04.4 · Volume Profile` 再加入约 2780 个中文字符的理论正文、三个对照案例和 36 分钟预计阅读时间。第三轮继续到 `失败接受后的结构确认`，为 `01.2 · BOS 与 CHoCH` 加入约 2891 个中文字符的理论正文、三个对照案例和 39 分钟预计阅读时间。第四轮沿 `高质量结构破坏的起点与失衡` 深挖区域生命周期，为 `01.4 · OB、Breaker 与 FVG` 加入约 2520 个中文字符的理论正文、三个对照案例和 41 分钟预计阅读时间。第五轮将全路径接入 Footprint、Delta、Absorption 和成本后风险，为 `02.4 · 合流实验室` 加入约 2555 个中文字符的理论正文、三个对照案例和 43 分钟预计阅读时间。

长章节采用“问题导入 → 朴素解释与精确定义 → 连续机制 → 模型假设 → 内生/外生变量 → 逐步算例 → 比较静态 → 证据阶梯 → 成立/失败/冲突案例 → 误解反驳 → 分层练习 → DFS 导航”的结构。它借鉴经济学入门教材组织理论和应用的方法，但交易事实仍由交易所、监管教育材料及明确标注的框架来源支持。图片、图表与交互只作为正文的辅助证据，不能替代概念论证。

第一轮把流动性拆成显示深度、已成交数量、成交质量和 SMC 位置标签，并用 180 手立即买入的逐档成交例子计算成交均价与价格冲击。三个案例分别展示外侧接受失败、把长影线误判为 Sweep、以及低周期拒绝与高周期扩张冲突时的 No Trade。所有数值均为教学模拟。

第二轮把“突破后没有立刻跌回”改写为一个可检验的接受模型：在固定观察窗内，同时观察外侧停留占比、外侧成交占比、价值中心迁移幅度和回测深度。例题使用 12 个时间块、1500 手成交量与逐步上移的 Developing POC，说明单一收盘价为什么不足以证明接受。三个案例分别覆盖接受成立、早盘假迁移、以及 TPO 与成交中心冲突时的 No Trade。所有阈值和行情仍为教学模拟，不是交易信号。

第三轮把结构标签拆成“破坏了哪一层摆动、怎样破坏、破坏后是否保持”三个问题。章节先固定父级/内部摆动和受保护点，再用相对范围、实体效率、方向收盘位置、重叠和后续接受衡量 Displacement。例题逐步计算 `K=2.58`、实体效率 `80.6%` 与看跌收盘位置 `87.1%`，但只把结果称为高质量 CHoCH 候选。三个案例分别展示父级破坏成立、新闻长影线的失败反例，以及低周期向上与小时空头冲突时的 No Trade。

第四轮把区域拆成“几何构造 → 形成原因 → 回访反应 → 失效 → 角色转换”。FVG 只先陈述三柱非重叠，OB 必须关联预设位移与结构结果，Mitigation 要记录进入深度和后续恢复，Breaker 则要求原候选失效、另一侧接受、结构进展和反向回测。例题同时计算 FVG 回补率、OB 进入率和计划盈亏比，并展示止损距离扩大时毛 4R 如何下降为约 2.10R。

第五轮把合流改写为四道不能互相补票的硬门：位置、结构触发、主动流量与价格响应、成本后的净风险。例题先由 `Delta = −500` 得到吸收候选，再要求结构收回，最后把毛 `2.44R` 重算为净 `2.04R` 并按风险预算反推数量；若确认太晚，净值降到 `0.97R`，模型正式输出 No Trade。五轮路径至此结束，后续应转入逐根回放、完整样本记录和样本外策略评估，而不是继续堆术语。

术语词典包含 62 个可跳转课程的知识点。每个知识点除简明定义外，还可展开查看“描述什么、怎么识别或计算、怎样区分相近概念、实际看什么、最容易误判什么”五层讲解；搜索框支持中文输入法，也会检索这些详细内容。

## 盈亏比与策略期望课

`00.5 · 1R` 现在区分三件事：单笔计划盈亏比、扣除成本后的净盈亏比，以及一组交易的策略期望。若胜率为 `p`、实际平均盈利为 `W`、实际平均亏损为 `L`、平均每笔成本为 `C`，统一用事前 1R 表示，则 `E[R] = p×W − (1−p)×L − C`，保本胜率为 `pBE = (L+C) ÷ (W+L)`。

交互计算器允许调整胜率、平均盈利、平均亏损、成本和目标期望，显示盈利贡献、亏损贡献、成本拖累、当前期望、保本胜率，以及为了达到目标期望所需的最低平均盈利。课程同时给出止损优先的数量计算、实际结果复盘、回撤与样本外验证清单；所有输出都是抽象计划与压力测试，不是未来收益预测。

## 进阶知识扩容

- **时间上下文**：区分日历日、交易日、RTH、ETH、交易所时区与固定 GMT 偏移，提示夏令时错位风险。
- **相对坐标**：强调 Internal / External Liquidity 与 Premium / Discount 都依赖先声明的父级范围；改变锚点，分类会改变。
- **历史成交分布**：以 POC、Value Area、VAH、VAL、HVN 与 LVN 描述已经发生的成交分布，并明确它们不是方向预测器。
- **足迹与拍卖语言**：拆开对角不平衡、Stacked Imbalance、Excess 与 Unfinished Auction，并提示不同软件的计算口径可能不同。
- **盘口事件**：把 DOM 从静态截图改写为 Stacking、Consumption、Pulling、Replenishment 的事件序列；Spoofing 需要“下单时意图”的监管判断，不能由截图直接定性。

## 马丁网格风险课

`00.7 · 马丁网格：均价变近，尾部风险变大` 将普通等额网格、定时 DCA、马丁加仓和马丁网格分别定义。交互敞口阶梯允许切换成交层数、`1× / 1.25× / 1.5× / 2×` 仓位倍率、止损距离和目标距离，同时查看累计数量、加权均价、计划止损风险、计划目标回报、回报风险比、当前浮动 P&L，以及再跌一格对全部仓位造成的新增 P&L。

多层做多持仓的统一计算为：`计划止损风险 = 总数量 ×（加权均价 − 止损价）`，`计划目标回报 = 总数量 ×（目标价 − 加权均价）`，`Reward/Risk = 目标回报 ÷ 止损风险`。止损应由结构失效决定，再根据风险预算反推数量；为了保住既有数量而把止损外移，会直接扩大 1R。

所有数值都是抽象计划值，不包含手续费、Spread、Slippage、资金费、保证金或交易所强平公式。普通 Stop 的触发价格也不保证等于最终成交价格。课程不会提供实盘倍率、网格区间、仓位、止损距离或机器人参数建议，也不会用大量小盈利掩盖持续单边行情中的尾部风险。

## 结构案例室

案例室包含六个使用模拟 OHLC、Delta 与 Footprint 数据构建的学习档案：

1. 扫低之后的看涨结构延续
2. 等高上方的买方流动性陷阱
3. 失效 Order Block 转换为 Breaker
4. FVG 回补后的原趋势延续
5. 极端正 Delta 与高位吸收
6. 高周期看多、执行证据冲突时的 No Trade

每个案例分成五个证据阶段。结构、流动性、区域与成交图层可以独立开关；完整复盘按照事实、推断、失效、决策、常见陷阱和替代解释分栏。案例数据是人为构造的教学素材，不是历史回测或策略有效性证明。

## 启动

需要 Node.js 20 或更新版本，不需要安装第三方依赖。

```bash
npm start
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。开发时可使用：

```bash
npm run dev
```

## 本地设置

```bash
HOST=127.0.0.1 PORT=8080 UPDATE_INTERVAL_HOURS=12 npm start
```

- `HOST`：监听地址，默认 `127.0.0.1`。只有明确部署到受控服务器时才设置为 `0.0.0.0`；这会让服务对允许访问该端口的网络开放。
- `PORT`：服务端口，默认 `4173`。
- `UPDATE_INTERVAL_HOURS`：来源定时检查间隔，默认 `24` 小时，最小 `1` 小时。

仓库包含一个用于 Linux systemd 的参考单元 [`deploy/glearn.service`](deploy/glearn.service)。它从 `/opt/glearn` 启动服务，以专用 `glearn` 用户运行，只允许应用写入 `data/runtime`，并显式设置 `HOST=0.0.0.0` 与 `PORT=4173`。公开部署前还应通过主机防火墙或云安全组确认端口访问范围；当前应用没有账户隔离，学习进度与更新台状态在同一个服务实例中共享。

定时任务只在服务器运行期间执行。更新台中的“立即检查全部来源”可以手动建立或刷新来源基线。

## 更新机制

1. 服务器读取 `data/sources.json` 中的公开网页。
2. 清理脚本、样式和易变时间文本后计算正文 SHA-256 指纹。
3. 页面变化时比较 H1–H3 目录，生成“待审核候选”。
4. 接受候选只表示它值得成为写作线索，不会自动修改 `data/content.json`。
5. 可以从更新台增加新的 HTTP/HTTPS 来源；新来源在下一次检查时建立基线。

这种设计有意保留人工审核边界：外部页面、社区脚本和推广内容都不能自动成为已发布的金融教育材料。
